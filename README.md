# Programming Problems

這個 repository 用來記錄我以 C++ 練習的程式解題。

## 資料夾說明

- `LeetCode/<難度>/`：正在進行中的 LeetCode 題目。
- `LeetCode/<難度>/Finish/`：已完成的 LeetCode 題目。
- `kattis/`、`zerojudge/`、`NTOJ/`：其他線上解題平台的練習。
- `test/`：本機測試程式。

## 檔案命名

新寫的 LeetCode 題目在本機可使用 CamelCase，例如：

```text
492ConstructTheRectangle.cpp
```

每日同步到 GitHub 前會自動整理為：

```text
0492-construct-the-rectangle.cpp
```

同步不會變更題目的程式內容，也不會自動在進行中與 `Finish` 資料夾之間移動檔案。
